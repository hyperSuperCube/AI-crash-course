# AI crash course

Hands-on notebooks for learning modern AI methods from scratch.

## Contents

- `Dreamer.ipynb` — a runnable walkthrough of the original Dreamer
  (*Dream to Control: Learning Behaviors by Latent Imagination*, ICLR 2020,
  arXiv:1912.01603): world model, actor and critic trained from pixels on a
  small slider-control task.
